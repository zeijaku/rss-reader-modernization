# V1.55 D4 — Memo management

Settings modal adds saved-snapshot Copy, TXT and Markdown downloads; no extra header icons. It ignores supplied owner/body/location. No retry on failure; stale snapshot requires refresh. Existing Widget-create reload on success; block active inline drafts and explicitly confirm disposal of current unsaved settings before duplicate. Failure preserves draft.

Downloads use the saved source already loaded on the owned card; no new download endpoint, no server file or external network. Markdown is UTF-8 raw source (including Text format); TXT preserves Text verbatim and converts supported Markdown via D2 safe DOM to plain text, retaining list/check markers, code, table tab separators and link URLs. UTF-8 without BOM, LF source, sanitized ID-prefixed filenames. Downloads never save or use unsaved form input. No HTML execution or external resources. Timestamp in card footer uses existing stored server datetime (minute display, seconds in datetime/title); counter shares footer. Inline saves, checklist and manual refresh update the timestamp, settings card replacement uses server-rendered timestamp. No new migration.

Focused SQLite tests exercise owner, stale revision, Unicode title, exact body, independent edit, rollback, soft-delete rejection.
