# V1.43.1-dev.2: Dashboard card chrome normalization

Application / Asset Revision: `1.43.1-dev.2`。

## 再調査で確認した原因

- Dashboard Widgetは同じ見た目でも実装元が複数あり、外枠とheaderのCSSが統一されていなかった。
- Mailは`.mail-card-inner`に角丸がなく、header側には古い`min-height:42px`が残る。
- Information系はJavaScriptがPage load後に`.information-widget-inner{border-radius:.4rem}`等を注入する。
- Calculator / Blind Spotも`clock-timer.js`から個別CSSを後挿入する。
- XはBootstrap系`.375rem`、Game/Feed/Cameraは4px系など外枠radiusが混在する。
- そのため、headerだけ44pxへ指定しても外枠clip/border/table構造の違いで見た目が揃わなかった。

## dev.2 共通規格

- Dashboard Card外枠: `border:1px`。
- Dashboard Card外枠: `border-radius:4px`。
- Dashboard Card外枠: `overflow:hidden`でheader背景を同じ角丸へclip。
- div系Header: `flex:0 0 44px` + `height/min-height/max-height:44px`。
- Feed/Search Feed: `thead / tr / th / inner`を44px契約へ固定。
- 既存個別CSSが後から挿入されても共通規格が勝つよう、`#main-content .dashboard-widget` scopeと必要箇所の`!important`を使用する。

## 対象

Feed / Search Feed / Clock / Memo / Task / Calendar / Links / Weather / Game / Mail / Earthquake / Sun & Moon / Air Quality / Connection Monitor / Blind Spot / Calculator / Camera Video / X。

## 非対象

各Widget bodyのlayout、機能、API、保存、Game、Calendar、RSS取得、Mail取得、Remote Files、DB、Authは変更しない。

## Playtest

1. 異なるWidgetを横並びにし、headerの上下端が44pxで一致すること。
2. Mailを含め、すべてのCard上端が同じ4px角丸になること。
3. Feed/Search Feedの色付きtable headerも他Widgetと同じ高さに見えること。
4. Connection Monitor / Weather / Blind Spot / Calculator等、後挿入CSSを持つWidgetも同じ外枠になること。
5. DesktopのPage Topに左右余白があり、Smartphoneは48×48 arrow-onlyのままであること。
