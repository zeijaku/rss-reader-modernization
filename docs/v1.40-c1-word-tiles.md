## 本番確認（最終検証後）

1. GitHub PHP 8.1/8.4 CI通過を確認した配布ZIPを使用してください。
2. 適用前提はV1.40-B 1.40.0-dev.3です。現在のVersionと対象ファイルをバックアップします。1.39.2へC1差分だけを適用しないでください。
3. 最終検証済みZIPの案内後、app/・public/を同じ階層へ上書きし、Version 1.40.0-dev.4を確認します。DB・設定・Credential変更はありません。
4. 先にRSS・Memo・Task・Calendar、Maze Chase・Falling Blocks・既存Gameの通常操作を確認します。
5. GameメニューにWord Tilesが1個表示され、選択で追加画面のGameとタイトルがWord Tilesになることを確認します。
6. Startを押します。独自9×9盤面と7枚の手札が表示されます。初手は中央を通す必要があります。Bonusなし・各文字1点です。
7. 手札C、A、Tを選び、5行4列・5行5列・5行6列へ置きます。未確定の状態で再読込し、配置が復元されることを確認します。確定するとCAT・3点になります。
8. 残るR・Eを6行5列・7行5列へ置き、縦のAREを確定します。3点加点、合計6点になります。盤面・手札・Scoreが再読込後も残ることを確認します。
9. 未登録のCTA、空白のある配置、離れた単語などが拒否され、Scoreが増えないことを確認します。未確定Tileの再クリック／配置取消で修正できます。
10. Pause中はTileと操作ボタンが無効になります。Modal開閉や別Tabから戻っても手動Pauseを維持します。Resumeで続けます。
11. 手札交換、Finishで終了、Restartで盤面とScoreを初期化しBestを保持することを確認します。交換で同じ文字が戻ることもあります。
12. 拡大・縮小・Escape、Dark Theme、KeyboardのTab/Enter/Spaceと盤面内の矢印移動を確認します。盤面外の矢印は通常のページ操作になります。
13. Wordを2個とMaze／Fallingを配置し、Score・盤面・保存が独立することを確認します。サイズ・色・見出し・並び替え、種別変更／削除後の旧UIと保存データの削除も確認します。
14. SmartphoneとStockでも追加・手札→盤面のTap・確定・Pause・拡大を確認します。WordなしのTabではword-tiles.jsを要求せず、配置時だけ現在Asset Revisionで1回読むことを確認します。
