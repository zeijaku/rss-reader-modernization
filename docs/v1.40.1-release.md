# V1.40.1 正式版

dev1〜dev5で本番確認済みのUI改善を正式配布します。Application Version / Asset Revision はともに `1.40.1`。正式化ではdev5のUI実行コードを変更せず、Versionと文書を整えます。

## 変更内容

- DrawerをWidget追加・表示・管理へ整理し、カテゴリ矢印の見切れを修正。
- Account Settingsを基本・セキュリティ・認証ログに分け、基本を先頭に表示。
- Settingsを表示・Dashboardタブ・ユーザーリンク・RSS Highlightへ整理。既存アンカー/保存契約を維持。
- Widgetヘッダーのタイトル・操作ボタン・内側フォーカスを整える。44pxヘッダーと既存ドラッグ/操作を保持。
- Navbar通知ベルとMemo/通知センターのTheme対応、閉じるX、Navbarフォーカスを改善。
- スマホのページ先頭ボタンを48×48pxの矢印のみ、300pxを超えるスクロールで表示。PC表示と100px閾値、フォーカス復帰、reduced-motion対応を維持。

DB Migration、必須Config、新規Dependencyはありません。認証・owner scope・CSRF・API・Game engineを変更しません。表示/リンク設定は従来どおり同じFormで一括保存され、各タブの保存範囲表示を維持します。

## 本番への適用

1. Application、config/local.php、DB、private runtime dataをバックアップ。
2. 正式Runtime ZIPとSHA-256を確認。Complete Source ZIPは開発・監査用。
3. dev5適用済みなら正式化差分の `app/version.php` だけを同じ相対パスへ上書き。
4. 1.40.0からは累積app/public差分またはRuntimeを利用。Config/private data/DBを維持し、既存DBへschema.sqlを実行しない。
5. OPcacheは既存運用手順で更新し、ブラウザ再読込でVersion `1.40.1`、JS/CSSの正常取得を確認。
6. Drawer、Accountの基本タブ、Settingsタブと保存、Widgetヘッダー、通知ベル/Memo/通知X、PC/スマホのページ先頭ボタンを確認。
7. Feed/Stock、Game、Calendar、通常スクロールに変化がないことを確認。

dev5から戻す場合はバックアップしたdev5のversion.phpを復元します。1.40.0へ全体を戻す場合は全対象ファイルを同じバックアップ時点へ戻します。DBロールバックは不要です。
