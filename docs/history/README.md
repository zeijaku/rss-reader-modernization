# Secure Baseline early hotfix history

- `sb00-02-hotfix-r2.md` — shared hosting / private config / PDO境界
- `sb00-02-hotfix-r3.md` — Login UI regression
- `sb00-02-hotfix-r4.md` — silent login failure
- `sb00-02-hotfix-r5.md` — session storage / redirect persistence
- `sb00-02-hotfix-r6.md` — logout route / session termination
