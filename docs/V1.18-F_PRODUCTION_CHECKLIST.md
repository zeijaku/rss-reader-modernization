# V1.18-F Production Checklist

## Deployment requirement
If V1.18-E is already installed and working, **no production file deployment is required for V1.18-F**.
There is intentionally no production-code delta in this phase.

The ZIP still contains the cumulative V1.18 production files for comparison and safe relative-path
overwrite if needed.

## Recommended confirmation
Because F does not change runtime code, only a short sanity check is needed:

1. Open a page containing Connection Monitor.
2. Confirm the monitor still reaches `Online` and shows latency/history/state as in V1.18-E.
3. In DevTools Network, filter by `connection_probe.php`.
4. Confirm the health request target is the same RSS Reader origin and returns HTTP 204.
5. Confirm no periodic request to Google, Cloudflare, Fast.com, public IP addresses, or another external monitoring service appears because of Connection Monitor.
6. Confirm there is no Speed Test button or automatic large download generated by Connection Monitor.
7. With multiple Connection Monitor widgets, confirm the page still performs approximately one shared probe every 5 seconds in the foreground.

## Expected result
V1.18-F should look and behave exactly like V1.18-E. The phase result is the finalized scope decision,
not a new runtime UI.

## Not required
- No SQL or migration.
- No configuration/local.php change.
- No external API key.
- No new browser permission.
- No full regression test at this phase.
