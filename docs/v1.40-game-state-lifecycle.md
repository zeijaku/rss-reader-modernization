# V1.40 Game Widget fixes — 1.40.0-dev.7

Base: C3 d22b0539fb0d6c97a7fc2ebe501b43fb4d1e52b4 (1.40.0-dev.6). Main remains 1.39.2. Application and Asset Revision are both 1.40.0-dev.7. This checkpoint fixes two issues; it does not perform a legacy engine rewrite or formal release.

## Changes

- English/Japanese Word Tiles settings switches preserve both independent snapshots (board, rack, bag, pending turn, status, Score) and Best. Both normal partial-refresh settings and legacy reload settings use this policy. Same-language title/color/size updates preserve progress. Widget deletion removes both languages only in the current user/widget scope. Changing to another game retains the existing reset policy; Japanese now follows the same cleanup policy as English.
- Wire Defense card refresh calls its existing initializer. Detached/replaced/type-changed cards cancel RAF, unregister visibility/pagehide and card input listeners, and release runtime references. One removal observer exists only while Wire cards exist and disconnects after the last removal. Drag moves that reinsert a card in the same DOM batch keep the connected card. Existing game mechanics and record schema stay intact.
- No database, API, authentication, CSRF, owner scope, dictionaries, CSS or external dependencies change. Stock does not display Game Widgets; its menu consistency is outside this patch.
