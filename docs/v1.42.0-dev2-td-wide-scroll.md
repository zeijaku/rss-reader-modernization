# V1.42.0-dev.2: Tower Defense 2列幅Scroll修正

Application / Asset Revision: `1.42.0-dev.2`。

Base: `1.42.0-dev.1`。Calendar `1.41.1-dev.1`を親にした既存TD Branchを継続し、Map / Route / Difficulty / Saveは変更しない。

## Problem

Production playtestで、広域Stageを横3列にすると1080px盤面全体が見える一方、横2列では内部Scrollが成立せず、中央付近だけが切り取られたように見えることを確認した。

dev.1のBrowser testは `scrollWidth === 1080` と `clientWidth <= scrollWidth` までしか要求しておらず、Desktop 2列で `clientWidth === 1080` のまま外側にclipされるケースを防げていなかった。

## Fix

- 広域時の `.td-widget` をGame Cardの実幅以内に明示的に制約する。
- `.game-widget-stage` も `width/max-width:100%` と `min-width:0` で縮小可能にする。
- 1080px固定の `.td-board` 自体は変更しない。
- `.td-board-scroll` を最大1080px・Card内100%幅とし、狭い場合だけ内部横Scrollする。
- 十分な幅がある3列相当では1080px全体をそのまま表示する。

## Runtime files from dev.1

- `app/version.php`
- `public/css/game-widget.css`

DB Migration / config変更 /削除fileなし。

## Verification

- Desktop 2列: `scrollWidth === 1080` かつ `clientWidth < scrollWidth`。
- Desktop 2列: `scrollLeft` を変更でき、左右へ移動可能。
- Desktop 3列相当: 幅が1080px以上なら全体表示。
- Smartphone: 盤面のみ横Scrollを維持。
- Document全体の横Overflowなし。
- Stage / Route / Tower / Difficulty / Save / Calendarに変更なし。

正式Release / Production反映はこのCheckpointに含めない。
