# V1.43.0 正式版

Cursor Fieldを固定Grid型から自由移動する少数Bodyの物理フィールドへ刷新した正式版です。Application Version / Asset Revision は `1.43.0`。

## 適用

1. Application、`config/local.php`、Database、private runtime dataをバックアップします。
2. GitHub Releaseの正式Runtime ZIPとSHA-256を確認します。Complete Source ZIPは開発・監査用です。
3. V1.42.0からは追加SQLなしで正式Runtimeを展開します。既存設定・DB・private dataを維持し、既存DBへ `database/schema.sql` を実行しません。
4. OPcacheとBrowser cacheを更新し、Version `1.43.0` を確認します。
5. Cursor Fieldで初期3個の○/□が低速で漂い、内壁・物体同士で反射することを確認します。
6. Mouse / Pen Cursorを当てるとBodyが反射し、速く動かしたCursorで勢いが変わることを確認します。
7. 空白Clickで静止Bodyが追加され、物体上Clickでは追加されないことを確認します。
8. Widget幅を変更してもBody数とおおよその位置が維持されることを確認します。
9. 他Game / Calendar / RSS / Mail等の既存挙動に変化がないことを確認します。

## Compatibility

- V1.42.0からのDB Migrationなし。
- config変更なし。
- 認証/API/Owner scope変更なし。
- 他Game / Calendar runtime変更なし。
- Cursor Fieldの保存機能は追加していないため、Reload時は初期状態へ戻ります。

## 検証・公開

正式化PRのPHP 8.1 / PHP 8.4 CI → mainへmerge → main CI → `.github/release-request.txt` を `1.43.0` へ更新する公開PR → 共通Release WorkflowのRuntime/Complete Package・SHA-256・secret scan・clean-room・Artifact Attestation → `v1.43.0` Tag / GitHub Releaseの順で公開します。

正式AssetはRelease Workflowで生成したものを使用します。GitHub Release公開とProduction Deploymentは別工程です。
