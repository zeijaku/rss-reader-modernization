# V1.40.0 正式版

Game Widget拡張（Maze Chase / Falling Blocks / Word Tiles英語・日本語）とdev.7の状態保持・Wire Defense修正を正式配布します。Application VersionとAsset Revisionはともに1.40.0です。

## 変更・互換性

既存のgame subtype / owner-scoped API / widget_configを利用し、複数配置できます。新規DB Table・Migration・必須Config・Dependencyはありません。既存Gameの全面Rewriteは行いません。Score・盤面は現在のブラウザ内に保存し、端末間共有はありません。

英語辞書43,127語、JMdict由来の日本語読み辞書40,000語を固定ローカル配布します。元の巨大辞書をRuntimeへ入れず、License・Attributionを同梱します。日本語派生辞書はCC BY-SA 4.0であり、アプリのMITと区別します。

## 適用順序

1. Application / config/local.php / Database / private runtime dataをBackupする。
2. 1.40.0 Runtime ZIPとSHA-256を確認する。Complete ZIPは開発・監査用。
3. dev.7を既に適用済みなら正式化差分ZIPのapp/version.phpを上書きする。1.39.2からならRuntimeまたは累積app/public差分を利用する。
4. config/local.php・var/のprivate data・既存Databaseは上書きしない。既存DBへschema.sqlを実行しない。
5. ブラウザを更新し、Versionが1.40.0になることを確認する。Asset Revisionの変更でJS/CSSを再取得する。
6. Game追加→各Game選択、Word英語⇔日本語の盤面/Score復元、Wire設定保存後のCanvas/Start/Best、Pause/削除を確認する。
7. PC/実機Smartphoneで既存ゲーム、RSS、Stock、Memo、Calendar、並べ替えと通常スクロールを確認する。

正式化ではゲームの実行コードをdev.7から変更しません。Word言語変更では双方の状態を保持し、Widget削除ではそのWidgetの両言語状態を消します。別ゲームへの変更は従来のリセット方針を維持します。Wire設定保存後はready/Start画面へ戻り、Bestを保持します。

## Release手順

正式化PRでmainへ統合→main PHP8.1/8.4 CI確認→release-request.txtを1.40.0へ更新→共通Release workflowのRegression/secret scan/Package/SHA-256/Attestation/clean-room完了→v1.40.0 Tag/Release確認、の順です。

Runtime/CompleteはRelease workflowが生成したものを正式Assetとします。本番環境への反映は別工程です。検証範囲・制限はRELEASE_NOTES.mdのVerification limitsを参照してください。
