# 1.53.0 更新手順

1. コード、DB、config/local.php、vendor、var、アップロード済みファイルをバックアップします。
2. 日付マークが未導入なら、Migration 036の@table_prefixをDB_TABLE_PREFIXに合わせて適用します。dev.20以降で適用済みなら再実行は不要です。
3. 正式Runtime ZIPのチェックサムを確認し、ZIP内のアプリケーションフォルダーからサーバーのアプリルートへ上書きします。
4. ページを再読み込みし、フッターと静的アセットが1.53.0になったことを確認します。
5. RSS表示、Reader、Stock、Calendarの月・週・日、検索・マーク・予定編集、利用するGPT Widget・Mail・Gameを確認します。

新規DBはdatabase/schema.sqlだけで構築します。既存DBにschema.sqlを再実行しないでください。

不具合時はバックアップしたコードへ戻してください。Migration 036のテーブルには日付マークが保存されるため、復旧時も保持します。

dev.26から更新する場合も、共通化済みCalendarヘッダーを含む正式Runtimeを使用できます。
