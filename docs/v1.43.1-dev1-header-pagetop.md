# V1.43.1-dev.1: Dashboard header / Page Top polish

Application / Asset Revision: `1.43.1-dev.1`。

V1.43.0からの小規模UI修正。機能追加は行わない。

## Changes

- Feed / Search Feedはtable header構造のため、内部`.feed-card-header-inner`だけでなく`thead tr`と`.feed-card-header`も44pxへ固定する。
- div型Widget（Game / Utility等）の既存44px header規格は変更しない。
- Desktopの`#page-top a`を64px→72pxへ広げ、左右6px paddingを追加する。
- 767.98px以下の48×48 arrow-only Page Topは変更しない。

## Scope

- Runtime変更: `public/css/dashboard.css` と version markerのみ。
- Game / Calendar / RSS取得 / Reader / Remote Files / Mail / DB / API / Authに変更なし。

## Playtest

1. FeedとGame/Utility Widgetを横並びにし、色付きheader上下端が揃うこと。
2. Search Feedでも44pxに揃うこと。
3. Desktopの「ページ上部」文字に左右余白があること。
4. Smartphoneでは従来どおり48×48の矢印のみであること。
