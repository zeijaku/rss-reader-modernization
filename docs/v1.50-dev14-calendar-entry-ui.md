# V1.50.0-dev.14 — Calendar event entry UX preview

Baseline: \`9097a0e2a45aaa673e640bb7643ee138d09ba491\` (V1.50.0-dev.13). Draft only. Do not merge into \`main\` or PR #180 without user approval.

## Scope
- Preserve existing Calendar create/edit/delete APIs, recurrence/occurrence scope, reminders, color, location, URL, notes and deadline highlight.
- Add a Bootstrap-themed event header and a modest accent to the date/time panel.
- Put the source calendar and event color side-by-side on desktop, stacked on mobile. Distinguish the source calendar color using an indicator.
- Keep repeat/reminder visible. Keep location, URL and memo in the existing disclosure panel.
- Add 30m / 1h / 2h duration shortcuts for timed events, maintaining end-date rollover across midnight. "指定" focuses the end time for manual adjustment.
- When switching to timed mode with blank hours, default to 09:00–10:00.
- No ICS integration and no schema changes.

## Manual regression checklist
1. New all-day event and timed event save; start/end dates and times persist.
2. Shortcuts: 30m, 1h, 2h; also 23:30 + 2h crossing midnight; custom end time.
3. Change an existing timed event without altering duration; switch all-day and back.
4. Repeat daily/weekly/monthly/yearly; edit single occurrence versus entire series; delete and restore exceptions.
5. Reminder, deadline highlighting, URL, location, memo, event color and Calendar source retain values.
6. Calendar filters, previous event copy, drag/drop and widget refresh remain usable.
7. Mobile (320px/375px), desktop; Bootstrap light, Slate and Solar themes; modal footer is visible while scrolling.
8. Keyboard focus, Escape/close, submitting only once, invalid input displays.

## Architecture
Additive \`public/js/calendar-entry-ui.js\` and \`public/css/calendar-entry-ui.css\` are loaded from \`public/js/calendar.js\`. Existing Calendar code owns state/API and remains authoritative. DOM nodes are moved, never cloned, to preserve their input identity and event handlers.
