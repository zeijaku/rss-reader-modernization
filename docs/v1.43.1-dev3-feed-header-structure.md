# V1.43.1-dev.3: Feed header structural normalization

Application / Asset Revision: `1.43.1-dev.3`。

## Root cause

Feed / Search Feedだけがheaderを`table > thead > tr > th`内に持っており、CSSで44pxを指定してもBrowser table layoutの影響で色付き領域が約40pxに見える状態が残っていた。

## Change

旧構造:
`feed-card-inner > table > thead > tr > th.feed-card-header > div.feed-card-header-inner`

新構造:
`feed-card-inner > div.feed-card-header.feed-card-header-inner + table > tbody`

Search Feedも同じ構造へ変更する。

## Compatibility

- `.content-title` / `.feed-card-actions` / edit / refresh classは維持。
- Search Feedの`.content-header`も新divに維持するため、no-reload style更新selectorは継続動作する。
- All RSS RecentはSearch Feedを拡張する既存処理をそのまま利用する。
- Feed tableのcolgroup / tbody / article row構造は変更しない。
- DB / API / RSS取得 / Reader / Game / Calendar / Mail / Remote Filesに変更なし。

## Verification

1. Feed / Search Feed / All RSS Recentのheaderが他Widgetと同じ44pxに見えること。
2. Feed headerがDOM上でDIVになり、tableの外に存在すること。
3. Feed refresh / edit、Search Feed refresh / editが従来どおり動作すること。
4. Article body・Stock・Summary操作が従来どおり動作すること。
5. Memo / Game / Mail / Blind Spot等との横並びでheader上下端が一致すること。
