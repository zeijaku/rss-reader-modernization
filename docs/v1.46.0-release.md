# V1.46.0 正式版

Frontend legacy couplingを段階的に減らすModernization Releaseです。Application Version / Asset Revision は `1.46.0`。V1.45.0からのDatabase Migrationと必須Config変更はありません。

## 適用

1. Application、`config/local.php`、Database、private runtime dataをバックアップします。
2. GitHub Releaseの正式Runtime ZIPとSHA-256を確認します。
3. Runtime ZIPを既存Applicationへ展開し、既存`config/local.php`、Database、private dataを維持します。
4. V1.46.0では追加Migrationを実行しません。
5. 既存Databaseへ `database/schema.sql` は再実行しません。
6. 次のobsolete fileが旧環境に残っている場合は、V1.46.0のCode適用後に削除出来ます。
   - `public/css/calendar-polish-r3.css`
   - `public/css/drawer-v121b.css`
   - `public/css/drawer-v121c.css`
   - `licenses/hls.js-1.6.16-Apache-2.0.txt`
   - `licenses/fontawesome-5.3.1-LICENSE.txt`
7. OPcache / Browser cacheを更新し、Footer等のVersionが `1.46.0` であることを確認します。

旧CSSを残したままでもCurrent runtimeから参照されないため即時の動作影響はありませんが、正式V1.46.0と同じfile inventoryへ揃える場合は上記5fileを削除してください。

## Dashboard frontend

- Task / Memo / Game / Clock controllerを個別JavaScriptへ分割しています。
- 4 controllerのDOM/Event操作をNative APIへ移行しています。
- Shared Dashboard transportは既存CSRF / 401 / API error contract維持のためjQuery AJAXを継続します。
- Feed、Drag & Drop、Calendar、Mail等の高coupling領域はV1.46で移動していません。

## Task / Clock

- Task Item create / update / toggle / deleteは対象Task Widgetだけを再取得して更新します。
- Task Widget自体のcreate / update / deleteは従来どおりPage reloadです。
- 狭い1列ClockではCard実幅に合わせたfont sizingを使用し、文字切れを抑えます。

## hls.js

- hls.js 1.7.3を `public/js/hls-1.7.3.min.js` として同梱します。
- HLS Widget表示時だけlazy loadします。
- jsDelivrからhls.jsを取得しません。
- Native HLS fallback、Network / Media recovery、destroy lifecycle、自動再生なしの既存behaviorを維持します。
- HLS Playlist / Segment自体のCORS要件は従来どおり配信元に依存します。

## CSS

- CalendarのR3 polish runtime CSSを `calendar-polish.css` へ統合します。
- Drawerのvisual / mobile / catalog runtime CSSを `drawer-catalog.css` へ統合します。
- Calendar deadline、Bootstrap / Bootswatch Theme等の独立behaviorは変更しません。

## Dependency

V1.46でVersion更新する主要Dependencyはhls.jsだけです。

- Bootstrap 5.3.8: 維持
- Bootswatch 5.3.8: 維持
- jQuery 3.7.1: 維持
- Font Awesome Free 6.7.2: 維持
- hls.js 1.7.3: 更新・local vendoring
- PHPMailer 7.1.1: 維持

jQuery 4 / Font Awesome 7は将来の専用Migrationへ分離します。

## 確認

1. Login後、Dashboard / Stock / Settings / Drawerの基本操作を確認する。
2. Task Itemを追加・変更・完了切替・削除し、Page全体reloadなしで対象Task Widgetだけが更新されることを確認する。
3. Task Widget自体の設定変更が従来どおり反映されることを確認する。
4. 狭い1列Clockで時刻文字がCard外へ切れないことを確認する。
5. DrawerをDesktop / Smartphone幅で開閉し、Category、矢印、Modal遷移、safe-area表示を確認する。
6. Calendarの月表示、今日、直近予定、もっと見る、Deadline強調を確認する。
7. HLS Widgetを使用する場合はNetworkで `hls-1.7.3.min.js?v=1.46.0` がsame-originから取得されることを確認する。
8. hls.jsについて `cdn.jsdelivr.net` へのExecutable JavaScript取得がないことを確認する。
9. 利用している場合はMJPEG / YouTube /通常Videoも確認する。
10. Browser ConsoleでApplication由来のReferenceError / TypeError / 404 / hls.js Version Errorがないことを確認する。
11. 既存RSS、Search Feed、All RSS Recent、Calendar、Mail、Remote Files、Game、Account Security等の主要機能が従来どおり動作することを確認する。

FirefoxのYouTube iframeに関するFeature Policy、third-party Cookie、Dynamic State Partitioning、fingerprinting protection warningはThird-party / Browser Privacy側の通知で、RSS Reader Application Errorとは区別します。

## Database / configuration

- 必須Config変更: なし。

## 公開

正式化PRをPHP 8.1 / PHP 8.4 CI通過後mainへsquash mergeし、main CI確認後に `.github/release-request.txt` を `1.46.0` へ更新する公開PRをmergeします。

共通Release WorkflowがRuntime / Complete Source ZIP、SHA-256、secret scan、clean-room verification、Artifact Attestation、`v1.46.0` Tag / GitHub Releaseを生成します。

GitHub Release公開とProduction Deploymentは別工程です。
