# V1.40-C2 English dictionary checkpoint

Version/assets: 1.40.0-dev.5. Base: C1 2048fe666a03f0091a9d02d6d4b810baf8cb67a5 (Draft PR #105). Formal main remains 1.39.2. No DB, API, config or legacy-engine changes.

Word Tiles uses 43,127 fixed English words, including all 827 C1 entries. Pinned SCOWL 2020.12.07 commit 5ef55f9c42730ebe4394a78b77855468a6f15dd2: english-words and american-words levels 10,20,35,40,50 only. ASCII lowercase 2–9 letters, then uppercase, sorted and deduplicated; proper-name, abbreviation and variant word groups excluded. This is an original filtered game wordlist, not an official SCOWL distribution. Source: https://github.com/en-wl/wordlist/tree/rel-2020.12.07 . Full upstream notices (including WordNet and VarCon permissions/disclaimers) are shipped in licenses/word-tiles-scowl-Copyright.txt. Retain that file when redistributing. No external resources or API validation at runtime. No Japanese dictionary yet; C3 remains separate.

Reproduce offline: python3 tools/build_word_tiles_dictionary.py; verify with --check. Filtered source fixture and file hashes are in tests/fixtures/word-tiles/source.json. The original huge upstream dictionaries are not shipped. Runtime gets only the generated 434KB JavaScript wordlist; it loads once, only when Word Tiles is present, before the engine, with the same asset revision. Failure shows the existing retry UI. Search uses safe textContent, ASCII input, and a maximum 50 prefix candidates rather than rendering the complete dictionary.

C1 state format and storage keys stay unchanged (schema 1, wordlist 1 describes the compatible save format). Board, rack, pool, pending and score round-trip unchanged. Rules and scoring are unchanged; newly accepted English words are the intended behavioral expansion. Best is preserved. Dictionary membership applies to future moves; restoring a saved board never erases words. Returning to C1 preserves the same save shape, but new C2 words may prevent subsequent C1 moves.

Verification: dictionary reproducibility, C1 vocabulary retention, valid/invalid expanded words, C1 save compatibility, 100 seeded sequences, existing Maze/Falling pure runtime, PHP owner-scoped API checks and static contracts. GitHub CI run 36717670522 passed the full Current gate on PHP 8.1 and 8.4. Official Chrome Headless Shell executes Word PC/touch Dashboard/Stock checks and the existing 227-check Game regression. The local portable-PHP Current gate stops at Remote Editor HTTP JSON parsing; the unchanged B baseline reproduces the same failure. Standard Chrome cannot start its Unix singleton socket in this environment; Headless Shell works. Production behavior still requires the user checklist.

Production package must be based on B 1.40.0-dev.3 if C1 was not installed: include C1+C2 app/public changes, license and this document together. Never apply a C2-only delta to B or main 1.39.2. Back up every changed file first. No database migrations. Rollback to B requires restoring old files and removing the new Word engine and dictionary; browser state may be retained for a future reinstall.
