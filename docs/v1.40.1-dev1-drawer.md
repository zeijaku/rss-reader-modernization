# V1.40.1-dev1: Drawer整理

Application / Asset Revision: `1.40.1-dev.1`。
基準main: `08eb111f24aa7bebee12187b030958bb526323ee`（V1.40.0）。

## Scope

- 表示: 設定済みタブ1〜4、Stock一覧。
- Widget追加: Feed / Information / Utility / Media / Game。既存カテゴリID、全ボタンのModal target、Game preset、disabled状態を維持。
- ファイル: File Library / Remote Files。
- 管理・設定: RSS管理、タブ表示変更、表示設定、RSS Highlight。設定画面のタブ化・入口集約はdev3。
- ユーザーリンク: 設定済みリンク。既存の992px未満での表示条件を維持。
- アカウント: アカウント設定、ログアウト。ログアウトFormをPOST / CSRF tokenごと保持。
- Widgetカテゴリは最初は閉じ、行全体で開閉。矢印の固定幅・右余白を確保し、カテゴリ名の下線を除去。
- Drawerは最大320px / 画面幅90%。320pxの画面ではWidget一覧を1列にし、タイルを44px以上で押せるようにする。
- 機能・リンク先・既存ゲーム・Score保存・DB/API/認証・モーダルの内容は変更しない。

## Installation

V1.40.0の環境へ差分ZIPの`app/`、`public/`を同じ相対パスで上書きする。
新規`public/css/drawer-catalog.css`も必ず転送する。DB Migration・config変更は不要。
Application / Asset Revisionは両方`1.40.1-dev.1`。反映後にページを再読み込みする。
Rollback ZIPは変更前のファイルを復元する。新規CSSは旧JSから参照されないため残っていても動作へ影響しない。

## Production checks

1. ページ下部が`1.40.1-dev.1`になっている。
2. PCとSmartphoneでメニューを開き、表示 / Widget追加 / ファイル / 管理・設定 / アカウントの順を確認。
3. Widget追加のFeed / Information / Utility / Media / Gameを開閉。矢印が切れず、行全体を押せる。
4. FeedのRSS Feed / Search Feed / 全RSS新着 / Information Board / Mail / X Timelineを確認。
5. InformationのWeather / Earthquake / Sun-Moon / Air Quality / Connection Monitor / Blind Spotと、UtilityのTask / Calendar / Links / Clock / Memo / Calculatorを確認。
6. MediaのCamera / Videoを押して追加画面を開き、閉じた後に暗い背景が残らない。
7. Gameの11項目を順に押し、選択されたゲームが正しい。既存の配置可否はそのまま（Stock等の制約を変更しない）。
8. タブ / Stock / File Library / Remote Files / RSS管理 / 3つの設定リンクが従来の画面へ移動する。
9. 設定済みユーザーリンクがSmartphoneに表示される。PCのNavbarは従来どおり。
10. アカウント設定が従来の内容で開く。ログアウトを確認する場合は保存中の操作を終えてから実行する。
11. PCのEsc / Tab / Enter操作、Smartphoneのスクロール・画面回転、ブラウザ文字拡大でも見切れない。
12. Menuを閉じた後、Dashboardのスクロール、Widget更新・編集・並び替え、配置済みゲームが通常どおり動く。
