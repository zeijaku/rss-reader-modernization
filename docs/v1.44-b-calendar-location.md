# V1.44-B Calendar 場所 + Google Maps

## Scope

- Calendar予定へ任意の「場所」を追加する。
- 通常予定、繰り返しシリーズ、Occurrence単位の例外変更で場所を保持する。
- 予定追加/編集の詳細領域を「場所 / URL / メモ」の順で表示する。
- 場所が入力されている場合のみ「Google Mapsで開く」を利用可能にする。
- Google Mapsは検索URLを別タブで開くだけとし、API Key / Google OAuth / Places API / Maps埋め込みは使用しない。

## DB

Migration: `034_v1_44_calendar_location.sql`

- `calendar_event.calendar_event_location VARCHAR(255) NULL`
- `calendar_event_exception.calendar_event_exception_location VARCHAR(255) NULL`

既存行はNULLのまま維持される。Migrationは再実行可能。

## Compatibility

- URL、メモ、色、Reminder、Deadline、Calendar Source、繰り返し、Occurrence例外を維持する。
- Calendar Copyは場所もコピーする。
- Drag & Dropは場所を保持したまま日付だけを変更する。
- 所有者境界は既存Calendar更新経路の `owner + active row` 条件を継続利用する。
- 外部Calendar同期はV1.44-BのScope外。
