# V1.12-J Finalization

## Release scope

Version 1.12 combines two completed themes without adding a new feature in this checkpoint.

### RSS Highlight

- Per-user keyword registration and deletion.
- Up to 50 keywords; each keyword is up to 64 characters.
- Case-insensitive matching for Latin text.
- Multiple matches in one RSS title.
- Longer match wins when keywords overlap at the same position.
- Highlighting is shared by normal RSS Widgets and Search Feed.
- Highlight rendering uses text nodes plus `<mark>`; the original plain title remains the value used by Stock, Task and article actions.
- V1.12 requires `database/migrations/012_v1_12_feed_keywords.sql` for this feature.

### Mail Phase 2

- Folder-wide unread count.
- Existing unread-row emphasis retained.
- Browser-side `all / unread only` filtering.
- Last refresh time.
- Subject / From server-side search.
- Sender filter over the currently fetched result set.
- IMAP Folder selector with server-side folder revalidation.
- Selected Folder is stored in the existing Mail Widget `widget_config`; no new Mail migration is required.
- Body preview binds `widget_id + folder + UID`.
- Message list and body preview remain read-only (`EXAMINE`, `leaveUnread()`, `BODY.PEEK`).

Mail Phase 2 does not add send, delete, move, copy, mark-read/unread, append, or folder-management writes.

## Database / configuration

Compared with Version 1.11, Version 1.12 adds only:

- `database/migrations/012_v1_12_feed_keywords.sql`

Mail Phase 2 adds no table or column. No new `config/local.php` value is required.

## Finalization changes

V1.12-J intentionally avoids feature changes. It:

- changes the visible application marker from `1.12.0-dev.9` to `1.12.0`;
- records the completed V1.12 scope;
- updates the retained release/build helper scripts that were still pinned to Version 1.6.0 so the next GitHub release work targets Version 1.12.0;
- performs focused regression and package-safety checks.

The repository-oriented build helpers still expect repository documentation/tests that are not included in these deployment/checkpoint ZIPs. They are intended to be used after the V1.12 tree is overlaid onto the cloned GitHub repository, not as a dependency of the deployed application.

## Focused regression boundary

The finalization checks cover:

- PHP syntax for application/public PHP files;
- JavaScript syntax for project JavaScript files;
- RSS Highlight shared rendering path and safe `<mark>` construction;
- Keyword limits and Migration presence;
- Mail search/unread/folder validation paths;
- `EXAMINE`, `leaveUnread()` and `BODY.PEEK` retained;
- Folder + UID binding for body preview;
- absence of newly introduced Mail write operations;
- Version 1.12 release marker;
- no V1.12-J database migration;
- package exclusions for vendor, secrets and runtime data.

Actual IMAP interoperability and browser visual behavior still require the existing manual browser checks because this build environment does not contain the user's Mail server or credentials.
