# V1.44.0 正式版

Multiple Calendarと予定Location + Google Maps検索を正式配布するFeature Releaseです。Application Version / Asset Revision は `1.44.0`。

## 適用

1. Application、`config/local.php`、Database、private runtime dataをバックアップします。
2. GitHub Releaseの正式Runtime ZIPとSHA-256を確認します。
3. Runtime ZIPを既存Applicationへ展開します。既存`config/local.php`、Database、private dataを維持します。
4. 既存Databaseでは、`DB_TABLE_PREFIX` と各SQL先頭の `@table_prefix` を一致させます。
5. `database/migrations/033_v1_44_calendar_source.sql` を実行します。
6. 続けて `database/migrations/034_v1_44_calendar_location.sql` を実行します。
7. 既存Databaseへ `database/schema.sql` は実行しません。Fresh InstallではCurrent `schema.sql` のみで追加Migrationは不要です。
8. OPcache / Browser cacheを更新し、Version `1.44.0` を確認します。

共有Hosting等で旧dev Migrationの途中実行により `<prefix>calendar_source` だけ作成済みの場合も、正式033はそのTableを削除せず続行出来ます。正式033 / 034は `information_schema` を直接参照しません。

## 確認

1. 既存予定が「既定Calendar」に表示されること。
2. Calendarを2～3個作成し、名称・識別色を変更出来ること。
3. 「すべて」FilterでCalendarを複数選択し、非表示予定がMonth laneを消費しないこと。
4. 新規予定でCalendarを選択し、既存予定を別Calendarへ移動出来ること。
5. 既定Calendarは削除出来ず、別Calendar削除時は予定が既定Calendarへ移動して残ること。
6. 日／週／月、前後月、手動更新、部分更新が従来どおり動作すること。
7. Copy / Drag & Drop / 繰り返しSeries / Occurrence変更・取消でCalendar所属が維持されること。
8. Reminder、期日強調、予定色、URL、Memo、Task表示が従来どおり動作すること。
9. Locationを保存・変更・空欄へ戻せること。
10. 日本語、空白、記号を含むLocationからGoogle Maps検索を開けること。空欄時はMaps Linkが表示されないこと。
11. Calendar source markerがFilterと同じlayer-group iconで表示され、Calendar色を維持すること。
12. 予定追加／変更Modalで終日、時刻、繰り返し、Reminder、期日強調が整列し、Smartphoneでは1列へ落ちること。
13. Desktopで「すべて」Filter、次月、更新、追加が同じToolbar段に表示されること。

## Database

### Migration 033

- `calendar_source` Tableを追加します。
- `calendar_event.calendar_event_source_id` とIndexを追加します。
- 既存Ownerごとに「既定Calendar」を作成し、既存予定を割り当てます。
- 共有Hosting対応のため `information_schema` を使わず、非表示marker rowでDDL完了を記録します。

### Migration 034

- `calendar_event.calendar_event_location` を追加します。
- `calendar_event_exception.calendar_event_exception_location` を追加します。
- Location未設定の既存予定はNULLのまま維持します。
- 033と同様に非表示marker rowでDDL完了を記録します。

Migrationは **033 → 034** の順で実行します。

## Compatibility

- PHP 8.1+ / MySQL・MariaDB。
- Config変更なし。
- Google Maps / Places API Key、Google OAuth不要。
- Google Calendar / ICS / CalDAV同期は今回のScope外です。
- RSS / Stock / Mail / Remote Files / Account Security / Gameの機能変更なし。

## 公開

正式化PRをPHP 8.1 / PHP 8.4 CI通過後mainへmergeし、main CI確認後に `.github/release-request.txt` を `1.44.0` へ更新する公開PRをmergeします。既存Release WorkflowでRuntime/Complete Source ZIP、SHA-256、secret scan、clean-room verification、Artifact Attestation、`v1.44.0` Tag / GitHub Releaseを生成します。

GitHub Release公開とProduction Deploymentは別工程です。
