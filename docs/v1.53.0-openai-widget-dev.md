# GPT Widget 試験版 1.53.0-dev.17

GPT Widgetを初めて導入する場合は、RSS Reader 1.52.0-dev.3 に GPT Widget の dev.1 から dev.17 までの差分を順に適用します。GPT Widgetの dev.16 から更新する場合は、dev.17 の差分を適用します。dev.7 の適用時は音声入力用の `public/.htaccess` と `public/index.php` も同時に上書きしてください。各差分ZIPはアプリのルートに展開します。DBの移行は不要です。

## 利用設定

既存の `config/local.php` の `return [...]` に次の設定を追加します。実行環境の環境変数でも同じ名前を使えます。

```php
'OPENAI_API_KEY' => '発行済みのキーを設定',
'APP_OPENAI_USER_ID' => 7,
```

`7` は例です。Widgetを使うRSS Readerアカウントの `user_info.user_id` に置き換えます。ログイン中のDashboardでは `#main-content` の `data-dashboard-user-id` 属性で確認できます。`APP_OPENAI_USER_ID` に一致するログインユーザーだけがWidgetを表示・利用できます。

サーバー既定のモデルは `APP_OPENAI_MODEL` で指定でき、未指定時は `gpt-6-luna` です。Widgetの設定で「使用モデル」を選び「モデルを保存」を押すと、そのWidgetの次回送信から反映されます。「記事をGPTに聞く」では質問ごとに選べます。候補の利用可否はAPIプロジェクトの設定に従います。PHP cURL拡張と `api.openai.com` へのHTTPS送信が必要です。発行済みのキーにはResponses（`/v1/responses`）のWrite権限を付けます。

## 試し方

1. ダッシュボードで「Widget追加 → Utility → GPT Widget」を選び、「新しい会話」を作成します。
2. 短い指示を入力して Shift＋Enter または送信ボタンで送り、回答を確認します。Enter で改行できます。送信中は入力欄の下の案内が「GPTが回答を生成中…」に切り替わります。使用モデルはヘッダー右側に表示されます。
3. 別の会話を作成し、一覧で元の会話に戻って履歴を確認します。長い履歴は会話欄の中でスクロールできます。

自分の発言は右寄せの色付きの吹き出し、GPTの回答は左寄せで表示します。GPTの回答では、HTTP・HTTPSのURLをリンクとして開けます。Markdownで囲まれたコードは言語名とコピーアイコン付きの枠で表示します。アイコンはコピーできるとチェックに変わります。見出し、箇条書き、太字、引用、文中のコードも整形して表示します。

ヘッダー右側の更新アイコンで会話を読み込み直せます。設定アイコンから「横幅」「縦幅」「見出し色」を選び、「外観を保存」を押すと即時に反映されます。横幅はダッシュボード共通の4段階で、スマホでは全幅になります。縦幅を「縦2段」にすると会話履歴欄が広がります。以前に追加したカードは保存済みの値「縦2段」が反映されます。これまでの履歴欄の高さに戻すには「標準」を選んでください。新しく追加するカードは標準で表示されます。Widgetの削除操作も設定画面にあります。

送信の隣にあるマイクを押して話し、停止ボタンを押します。日本語の認識結果が入力欄に追記され、送信前に編集できます。HTTPSとブラウザーによるマイクの使用許可が必要です。音声認識の対応状況はブラウザーによって異なり、ブラウザーが提供元の音声認識サービスを使う場合があります。

履歴は対象アカウントのWidget設定に保存されます。1カードに最大6件で、会話全体にも保存容量の上限があります。OpenAIへの各リクエストには、対象会話の直近6往復と新しい指示を含めます。Widgetを削除すると、そのWidgetの会話履歴も削除されます。

## 記事をGPTに聞く

記事の三点メニューで「記事をGPTに聞く」を選択すると、質問画面が開きます。GPT Widgetの配置は不要です。質問を書いて「送信」を押すと、記事タイトル・URL・一覧で利用できるRSSの概要（最大3,000文字）を添えて送信し、その場に回答を表示します。概要がない記事ではタイトルとURLを添えます。記事本文の追加取得や会話履歴への保存は行いません。利用額はGPT Widgetと共通の集計に含まれます。

## ファイル添付

入力欄のクリップから画像（PNG、JPEG、WebP）、PDF、UTF-8のテキスト・ログ・ソースなどを1ファイル選べます。上限は2 MBです。ファイルは質問と同時にRSS Readerサーバーを経由してResponses APIに送信され、履歴にはファイル名が残ります。後から同じファイルをもう一度読み込ませたい場合は再添付してください。サーバーのPHP設定やプロキシのリクエストサイズも添付の上限に影響します。

## API利用状況

ヘッダー右側のグラフアイコンにマウスを載せるか、クリック・タップすると利用状況を表示します。OpenAIのBillingで現在のクレジット残高を確認し、Widgetの設定で「基準残高（USD）」に入力します。以降のRSS ReaderからのGPT API利用額をトークン数と対応モデルの標準料金で概算し、推定残額に反映します。RSS Reader外の利用、追加購入、失効などは自動反映されません。基準を更新すると、その時点から集計し直します。

料金を計算できない応答がある場合は推定残額の表示を止めます。OpenAIからクレジット切れが通知された場合は入力欄の下に案内を表示します。集計はユーザー単位で、既存のサーバー書き込み領域 `var/security/openai-usage/` に保存します。
