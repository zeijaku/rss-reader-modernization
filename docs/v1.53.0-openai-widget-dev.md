# GPT Widget 試験版 1.53.0-dev.1

RSS Reader 1.52.0-dev.3 を起点とした差分です。差分ZIPはアプリのルートに展開し、`app/` と `public/` の配置を維持してください。DBの移行は不要です。

## 利用設定

既存の `config/local.php` の `return [...]` に次の設定を追加します。実行環境の環境変数でも同じ名前を使えます。

```php
'OPENAI_API_KEY' => '発行済みのキーを設定',
'APP_OPENAI_USER_ID' => 7,
```

`7` は例です。Widgetを使うRSS Readerアカウントの `user_info.user_id` に置き換えます。ログイン中のDashboardでは `#main-content` の `data-dashboard-user-id` 属性で確認できます。`APP_OPENAI_USER_ID` に一致するログインユーザーだけがWidgetを表示・利用できます。

モデルの初期値は `gpt-6-luna` です。変更する場合はサーバー設定の `APP_OPENAI_MODEL` に利用可能なモデルIDを指定します。PHP cURL拡張と `api.openai.com` へのHTTPS送信が必要です。発行済みのキーにはResponses（`/v1/responses`）のWrite権限を付けます。

## 試し方

1. ダッシュボードで「Widget追加 → GPT Widget」を選び、「新しい会話」を作成します。
2. 短い指示を送り、回答を確認します。
3. 別の会話を作成し、一覧で元の会話に戻って履歴を確認します。

履歴は対象アカウントのWidget設定に保存されます。1カードに最大6件で、会話全体にも保存容量の上限があります。OpenAIへの各リクエストには、対象会話の直近6往復と新しい指示を含めます。Widgetを削除すると、そのWidgetの会話履歴も削除されます。
