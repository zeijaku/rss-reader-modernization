# V1.40-B: Falling Blocks

Checkpoint `1.40.0-dev.3`, based on V1.40-A `1.40.0-dev.2` / commit `9d09aba4cfc733ca58f07dede811bc669802da4d`. This phase does not finalize V1.40.0, merge main, or deploy production.

## Scope and rules

- Existing `widget_type=game` and `{schema:1,title,game:"falling_blocks"}` config; same owner-scoped API, CSRF boundary, PDO and multiple placement model. No migration, table, API endpoint, framework or runtime dependency is added.
- Separate local `public/js/falling-blocks.js`; the shared entry lazy-loads this module only for configured Falling Widgets and inherits the current Asset Revision. Opening the Game menu alone does not load the engine.
- Original 10×18 board, seven geometric pieces, shuffled seven-piece bags, local wall/floor rotation offsets, Next label, left/right movement, clockwise/counterclockwise rotation, soft/hard drop, line clear, score, level and Game Over.
- Soft Drop gives 1 point per moved cell; Hard Drop gives 2. Clearing 1/2/3/4 lines gives 100/260/460/720 × current Level. Every 8 Lines increases Level. Gravity starts at 800ms and decreases by 55ms per Level, with a 90ms floor. Locking occurs immediately on a blocked drop; advanced lock delay and rotation systems are outside this initial scope.
- Keyboard: Left/Right, Up or X for clockwise rotation, Z for counterclockwise, Down for Soft Drop, Space for Hard Drop. Repeated Space/rotation events are suppressed. Keyboard handlers run only on the focused, active board; outside keys retain normal page behavior.
- Six touch/click controls with 44px targets. Each tap applies one action; native keyboard repeat handles horizontal movement/Soft Drop. No global touch/keyboard listener is added.
- Reuses Restart/Pause, expansion, Game Over status, Best and lifecycle. Animation stops on Pause, hidden widget/page, modal display, Game Over and destruction. Best remains local per user/widget/game; localStorage/sessionStorage/memory fallbacks. Current board state is not saved; Sound is OFF.
- Maze Chase engine and existing game engines are unchanged. Shared selection recognizes both new games. The pre-existing Stock Wire Defense option omission remains unchanged.

## 本番確認（順番に）

1. 現在のVersionがV1.40-A `1.40.0-dev.2`であることを確認し、差分ZIPの既存対象ファイルをバックアップする。1.39.2へB差分だけを適用しない。
2. B差分ZIP内の`app/`・`public/`を同じ階層へ上書きする。DB・設定・Credentialは変更しない。通常のCache/OPcache更新手順で再読込し、Version `1.40.0-dev.3`を確認する。
3. 先にRSS更新・Memo・Task・Calendarなど普段使う機能と、Maze Chase・Reversi・2048・Wire Defense等の既存Gameを確認する。
4. メニューのGameを開き、Falling Blocksが1個表示されることを確認する。押すと追加画面でGameと初期見出しがFalling Blocksになることを確認し、追加する。開始前は停止している。
5. Start後、盤面にFocusがある状態で左右キー、上/X、Zを試す。壁や積み上がったBlockを通り抜けない。盤面外や入力欄へFocusを移すと通常のページ操作になる。
6. 下キーでSoft Drop、SpaceでHard Dropを試す。得点が増える。Spaceを押し続けても、複数のBlockを連続して置かない。
7. 横一列を埋めて消去、複数行の消去、Scoreを確認する。8 LinesでLevelが2になり、落下速度が上がる。Next表示が次のBlockに切り替わる。
8. Pauseで盤面と自動落下が止まり、Resumeで再開する。手動Pauseのまま別Tabへ移動して戻る／Modalを開閉しても手動Pauseが維持される。
9. 積み上げてGAME OVER、Pause無効化を確認する。Restartで新しい盤面・Score 0・Level 1・Lines 0へ戻り、Bestは残る。
10. 拡大／縮小・Escape・TabのFocus移動、Dark Theme、画面Scrollを確認する。拡大中だけページScrollを止め、閉じると元に戻る。
11. Falling Blocksをもう1個とMaze Chaseを配置する。開始・得点・Pause・Restartが他のGameへ影響しない。並び替え、幅／高さ／色／見出し変更も確認する。
12. 再読込してBest保持を確認する。Game種別をMaze Chaseへ変更して戻す／削除し、旧盤面・入力・Animationが残らない。設定更新後の盤面は開始前へ戻る。
13. Smartphoneで追加、左右／左右回転／Soft Drop／Hard Dropの6ボタン、Pause、Restart、拡大を試す。各Tapは1操作。はみ出し、Dashboard Swipe・Drag・ページScrollとの競合を確認する。Stockでもメニュー表示と選択を確認する。
14. Fallingを置いていないTabでは`falling-blocks.js`を要求しないこと、置いたTabでは`?v=1.40.0-dev.3`付きで1回だけ読むことをNetworkで確認する。Gameメニューを開いただけでは読み込まない。
