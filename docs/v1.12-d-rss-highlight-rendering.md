# V1.12-D RSS Highlight rendering

## Scope

V1.12-D adds the first visible RSS Highlight rendering to the keyword backend/UI completed in V1.12-B/C.

- Applies to RSS Widget article titles.
- Applies to Search Feed article titles.
- Uses the existing shared `renderFeedItems()` path.
- Does not change Feed search conditions, fetched article data, Stock data, Task data, or Mail.
- Does not add a database migration.

## Rendering design

The title source remains the original plain string. Highlighting is applied only to the displayed title element.

`renderFeedKeywordTitle()` builds the title with `TextNode` and `<mark class="feed-keyword-highlight">` nodes. It does not convert a title or keyword into HTML with `.html()`.

The original title continues to be kept in `data-full-title`, `data-article-title`, and the feed render data used by the existing article actions. Therefore Highlight markup is not passed to Stock / Task / share / tooltip data.

## Match rules

- Partial string match.
- Case-insensitive for Latin alphabet through JavaScript RegExp `i` matching.
- Multiple keywords can match one title.
- Keywords are escaped before building the match pattern, so characters such as `+`, `.`, `(`, `)`, `[`, `]` are treated as keyword text.
- Longer keywords are ordered first. When keywords can start at the same title position, the longer keyword is highlighted instead of nesting marks.
- The initial version uses one common highlight color.

Example keywords:

- `OpenAI`
- `PHP`

Title:

`OpenAIがPHP対策を強化`

Only `OpenAI` and `PHP` are wrapped in the highlight mark.

## Live keyword changes

After a keyword is created or deleted in the RSS Highlight modal, currently displayed RSS / Search Feed titles are re-rendered immediately from their original `data-full-title` value. A feed refresh or page reload is not required just to see the new highlight state.

## Security boundary

V1.12-D intentionally does not use string-to-HTML replacement.

A title/keyword such as `<b>PHP</b>` stays text. The matched text is inserted into a `mark` node through `document.createTextNode()`.
