# V1.55 D3 — Memo editing

Shared editor session for existing inline, create and settings textarea. Existing raw source and revision API remain; no DB migration, new endpoint, auto-save or split view. Markdown-only toolbar inserts strong, emphasis, strike, heading, lists, task marker, link, inline code, fenced code and table. Selection-based insertion (line commands affect selected lines); reject toolbar operations exceeding 16000 Unicode code points. Preview replaces textarea visually, uses D2 safe renderer with non-interactive tasks and inert links. No changes sent until explicit Save (D2 normal-view checkbox remains an explicit write).

Undo/redo stores up to 100 body edit snapshots including selection in browser memory per editing session, keyboard Ctrl/Cmd+Z, Ctrl+Y/Cmd+Shift+Z, supports cancelable native history input; format/title/layout remain outside body undo history. IME composition grouped as one edit, editing commands and save blocked during composition. Synthetic composition browser checks are not physical Japanese IME tests.

Full screen reuses same textarea and history: inline editor temporarily moves into native top-layer dialog within its own card, then restores to original DOM position; settings/create use existing Bootstrap modal fullscreen class. Close fullscreen does not close the editing session. No separate draft. Touch buttons 44px; toolbars wrap. Save request locks editing controls; failures retain input, explicit success/cancel ends history. Manual refresh resets editor after confirmation. No change to other widget behavior. Browser tests run against actual PHP fixture, mock API and Chromium 1280/360px. Full integration and actual mobile devices remain pending. D4 management features and release unchanged.
