# V1.42.0 正式版

Calendar期日強調の1分間隔再明滅修正と、Tower Defenseの広域Map・複数Route・4 Difficulty・Save schema 2を正式配布します。Application Version / Asset Revision は `1.42.0`。

## 適用

1. Application、`config/local.php`、Database、private runtime dataをバックアップします。
2. GitHub Releaseの正式Runtime ZIPとSHA-256を確認します。Complete Source ZIPは開発・監査用です。
3. V1.41.0からは追加SQLなしで正式Runtimeを展開します。設定・private dataを維持し、既存DBへ `database/schema.sql` を実行しません。
4. OPcacheとBrowser cacheを更新し、Version `1.42.0` を確認します。
5. Calendarで「期日を強調する」が有効な前日〜期日の予定を表示し、初回パルス後もTab表示中に約1分間隔で再明滅することを確認します。Calendar APIの更新間隔は従来の3分のままです。
6. TDのStage 4〜6で24×8・2入口2経路を確認します。2列Cardでは盤面内を左右Scrollでき、十分な幅の3列CardまたはDesktop拡大では全体が見えることを確認します。
7. Easy / Normal / Hard / Nightmareを切り替えてMapが変化せず、開始資金/Base HP/敵圧が変わることを確認します。
8. ReloadしてStage/Difficulty/準備状態が復元されることを確認します。V1.41旧Saveがある場合はNormalへ移行し、旧keyを保持します。

## Compatibility

- V1.41.0からのDB Migrationなし。
- config変更なし。
- Calendarの既存deadline判定・recurrence/exception・手動更新・表示中3分更新を維持。
- TDの旧`.state`は上書きせず、新進行を`.state.v2`へ保存。
- 認証、Owner scope、Server API、cross-device sync、外部Game assetの追加なし。

## 検証・公開

正式化PRのPHP 8.1 / PHP 8.4 CI → mainへmerge → main CI → `.github/release-request.txt` を `1.42.0` へ更新する公開PR → 共通Release WorkflowのRuntime/Complete Package・SHA-256・secret scan・clean-room・Artifact Attestation → `v1.42.0` Tag / GitHub Releaseの順で公開します。

正式AssetはRelease Workflowで生成したものを使用します。GitHub Release公開とProduction Deploymentは別工程です。
