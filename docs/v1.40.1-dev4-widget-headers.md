# V1.40.1-dev4: Widget header presentation

Application / Asset Revision: `1.40.1-dev.4`. Stable main remains `1.40.0`.

## Scope

Runtime changes are only `app/version.php` and `public/css/dashboard.css`. Existing header markup, JavaScript events, drag behavior, API/owner/CSRF boundaries and Widget/game engines stay intact. The existing 44px header height and drag button are retained. The title has consistent padding/size/weight and bounded ellipsis; header action buttons are aligned and separated, with in-header keyboard focus. Desktop actions are 36px wide × 44px high; touch and narrow screens use 44px × 44px. The Mail unread badge can shrink on narrow cards while its text remains in the DOM.

All new CSS stays within `#main-content .dashboard-widget` and named header families. Only direct action buttons / known action containers are styled, preserving Feed title badges/new-item controls and body/modal/game controls. Known families include Feed/Search (also Information Board / All RSS when using the existing Feed header), Clock, Memo, Task, Calendar, Links, Weather, Games, Mail, Information/Connection Monitor, Blind Spot, Calculator, Camera/Video and X. Existing header colors and per-Widget buttons remain.

The rules apply automatically to cards rebuilt/refreshed by existing code, without a new observer, loader or handler. dev1 Drawer, dev2 Account and dev3 Settings behavior is retained. No DB, migration, external dependency, API or authentication-rule changes.

## Install

For an installation on dev3, back up and overwrite the two matching runtime files from the incremental ZIP. Keep the app/ and public/ paths. Reload and confirm `1.40.1-dev.4`. No migration or configuration changes. The cumulative ZIP includes dev1–dev4 for a stable V1.40.0 installation. The rollback ZIP restores the two files to dev3; no file removal or data rollback is required.
