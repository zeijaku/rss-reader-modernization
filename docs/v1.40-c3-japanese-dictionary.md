# V1.40-C3 Japanese Word Tiles checkpoint

Version/assets: 1.40.0-dev.6. Base C2 7f6b94b0656618d13b3cb1fe5b51bbf677ff0c9b. Formal main still 1.39.2. No database, migration, new API or credentials. Uses existing Game subtype word_tiles_ja with schema1 config. English word_tiles and every legacy Game retain their subtype and behavior.

Original 9x9 solo Word Tiles rules shared with the English engine. Japanese is a separate menu/add/edit option, adapter, dictionary, Best and state storage key. English initial rack CATRESO, vocabulary, tile counts and C1/C2 save format unchanged. Japanese initial rack さくらねこやま; fixed 82 character types / 132 total tiles. Small kana, voiced kana and long vowel mark are individual tiles, each worth one point. First move crosses center; later moves connect; every cross-word must be registered. Dictionary readings rather than arbitrary inflection, kanji or proper-name validation. Long vowels remain ー (こーひー), not rewritten as vowels. Score/history sharing across devices is not provided.

Japanese snapshot schema1/wordlist1/language ja has a strict 16KiB parser, character and fixed inventory validation. English/Japanese save data are rejected across language APIs. A dictionary refresh does not alter fixed tile counts. Deletion cleans only the user's target widget. Changing language preserves each language's state separately; saved words are not revalidated/deleted on restore. Rollback to C2 after switching Japanese widgets to an existing subtype avoids fallback to Icon Quest for unsupported Japanese config.

40,000 JMdict_e readings: snapshot 2026-09-30; SHA and filter manifest tests/fixtures/word-tiles/source-ja.json. Priority-tagged entries first; then general common nouns without technical fields; obsolete/archaic/rare/vulgar/derogatory/proper-noun entries excluded, NFKC, katakana to hiragana, 2-9 characters, deduplicated and capped. This is a filtered modified wordlist, not an official JMdict dictionary. Some uncommon or homophonous readings remain; no promise that every everyday word is included. Search is normalized (hiragana, katakana, half-width kana, combining voiced marks) and capped at 50 prefix results. Runtime never queries external APIs.
