# V1.40.1-dev5: 表示・操作の小さな改善

Version / Asset Revision は `1.40.1-dev.5`。Stable main は1.40.0のままです。dev4（通知ベル修正を含む）を基点に、次の5点だけを改善します。

1. Memo本文の背景と文字色をThemeの組に合わせる。
2. 通知センターの背景と空表示・読込・エラー文をThemeの組に合わせる。エラーは赤い側線でも区別する。
3. 通知センターの閉じるXをTheme文字色で表示する。既存Bootstrap SVGのmaskを利用する。
4. Navbarのキーボードフォーカス枠を操作部品の内側へ置き、PCヘッダーでの見切れを避ける。
5. 幅767.98px以下のページ先頭ボタンを48×48px、24pxの矢印のみとする。300pxを超えるスクロールで表示し、端末のsafe-areaを考慮する。PCの表示・100pxの閾値は維持する。

## 変更範囲

Runtimeは `app/version.php`、`public/css/dashboard.css`、`public/css/notification-center.css`、`public/js/dashboard.js` の4ファイル。JavaScript変更は既存ページ先頭ボタンの画面幅別閾値とresize時再判定のみです。クリックによるスクロール、main-contentへのフォーカス、prefers-reduced-motion対応、既存scroll/resize処理を維持しています。

DB、API、認証、owner scope、CSRF、Memo保存処理、通知処理、Gameロジック、依存関係は変更しません。通知ベルの既存Theme対応も保持します。HTMLの「ページ上部」文字とaria-labelは保持し、スマホでは見た目の文字だけを非表示にします。

## 配布・反映

- dev4適用済み: `rss-reader-v1.40.1-dev5-from-dev4.zip` の4ファイルを同じ相対パスに上書き。通知ベル修正前のdev4にも適用可能です。
- 正式1.40.0から: `rss-reader-v1.40.1-dev5-from-v1.40.0.zip` を使うとdev1〜dev5をまとめて反映できます。
- 反映前に対象ファイルをバックアップし、PHP OPcacheを使う場合は既存運用手順で更新してください。表示Versionがdev.5か確認し、必要ならブラウザを再読込します。
- dev5だけを戻す場合: `rss-reader-v1.40.1-dev5-rollback-to-dev4.zip` で、通知ベル修正済みdev4へ戻します。DB手順はありません。

## 本番での確認順序

1. Versionが `1.40.1-dev.5` であることを確認する。
2. PC・スマホでMemo本文を確認する。明るいThemeとSlate/Solarなど暗いThemeを切り替え、本文が読めること、編集・保存・再読込で内容が保持されることを確認する。
3. 通知ベルを開く。空表示・通知本文が読めること、Xで閉じられることを確認する。通知がある場合は既読・非表示・全既読も確認する。読込/エラー表示は発生した場合に確認し、通信障害を本番で意図的に起こす必要はない。
4. PCでTabキーを使い、ヘッダーのリンク・ベル・メニューへ移動する。フォーカス枠が見えること、Enterで操作できることを確認する。
5. スマホで少しスクロールした段階ではページ先頭ボタンが出ず、さらに下へ進むと48pxの矢印だけが出ることを確認する。端や端末の下部UIに隠れず、タップで先頭へ戻れることを確認する。縦横回転、Stock・設定画面でも確認する。
6. PCではページ先頭ボタンに従来どおり文字があり、クリックで先頭へ戻れることを確認する。OSで動きを減らす設定を使っている場合も確認する。
7. Drawer・アカウント/表示設定のタブ・Widgetヘッダー、Feed閲覧、Gameのキーボード/タッチ操作に変化がないことを確認する。

## 検証方法と限界

Focused gate `tests/test_current_ui_readability_browser.js` は実際のPHP Memo/modalとNavbar HTML、同梱CSS/JSを使います。APIは隔離したfixtureです。Bootstrap/Slate/Solar/Flatly × 1280/768/360/320pxで、Theme文字コントラスト、Memo編集内容、通知エラー/空表示/CSRF/閉じる、Navbarフォーカス、ページ先頭の閾値/サイズ/resize/フォーカス/通常とreduced-motion/200%文字を確認します。

既存Drawer・Account・Settings・Widget headers・Game settingsのブラウザ回帰とCurrent/CIも実行します。Headless Chromiumの検証は実機Safariや物理的なsafe-areaの確認を代替しません。本番の通知配送やMemo保存は上記の実機確認で補完してください。

Focused gate実行例:

```sh
GAME_TEST_CHROME=/path/to/chrome PHP_BINARY=/path/to/php node tests/test_current_ui_readability_browser.js
```

Playwrightは任意の検証環境で使用します。Application Runtimeへ追加しません。
