# V1.43.1 正式版

Dashboard Widgetの見た目を統一するUI maintenance releaseです。Application Version / Asset Revision は `1.43.1`。

## 適用

1. Application、`config/local.php`、Database、private runtime dataをバックアップします。
2. GitHub Releaseの正式Runtime ZIPとSHA-256を確認します。
3. V1.43.0からは追加SQLなしで正式Runtimeを展開します。既存設定・DB・private dataを維持し、既存DBへ`database/schema.sql`を実行しません。
4. OPcache / Browser cacheを更新し、Version `1.43.1` を確認します。

## 確認

1. Memo / Feed / Search Feed / Mail / Weather / Connection Monitor / Blind Spot / Game等を横並びにし、色付きheaderの上下端が一致すること。
2. Mailを含め、Card上端が4px角丸で統一されること。
3. Feed / Search Feed / 全RSS新着のheaderが他Widgetと同じ44pxに見えること。
4. Feed refresh / edit、Search Feed refresh / edit、記事表示、Stock / Summaryが従来どおり動作すること。
5. DesktopのPage Topが`ページ` / `上部`の2行表示で、Smartphoneでは48×48の矢印のみになること。

## Compatibility

- DB Migrationなし。
- config変更なし。
- API/Auth変更なし。
- RSS取得 / Reader / Mail transport / Remote Files / Game / Calendarの機能ロジック変更なし。

## 公開

正式化PRをPHP 8.1 / PHP 8.4 CI通過後mainへmergeし、main CI確認後に`.github/release-request.txt`を`1.43.1`へ更新する公開PRをmergeします。既存Release WorkflowでRuntime/Complete Source ZIP、SHA-256、secret scan、clean-room verification、Artifact Attestation、`v1.43.1` Tag / GitHub Releaseを生成します。

GitHub Release公開とProduction Deploymentは別工程です。
