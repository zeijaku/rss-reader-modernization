# V1.12-G Mail 未読UX

## 目的

V1.12-Fで確定したMail Phase 2方針に従い、IMAPサーバー上の状態を書き換えずに次の3点を追加する。

1. INBOX全体の未読件数
2. 表示中Mailの「未読のみ」切替
3. 最終更新日時

Checkpoint version: `1.12.0-dev.7`
Baseline: `rss-reader-modernization-1.12-F-mail-phase2-design.zip`

## 実装内容

### 未読件数

`mail_widget_read_latest()` でMail接続後、ImapEngineのFolder statusをread-onlyで取得し、`UNSEEN` を未読件数としてAPIへ返す。

未読件数はWidgetの表示上限5/10件の中だけを数えた値ではなく、INBOX全体の値とする。

API成功レスポンスには次を追加する。

```json
{
  "messages": [],
  "unread_count": 12,
  "fetched_at": "2026-08-10T11:54:00+09:00"
}
```

`fetched_at` はRSS Readerサーバー側で取得が完了した時刻であり、メールサーバーの更新日時ではない。

### 未読のみ表示

V1.12-F設計どおり、Gではブラウザ側Filterとする。

- `すべて`
- `未読のみ`

の2ボタンをMail Widget内に追加する。

Filterは取得済み5/10件の `message.unread` を使って表示を切り替えるだけで、Filter操作による追加IMAPアクセスは行わない。

そのため、未読件数が10件でも現在取得済み5件に未読がなければ、未読のみ表示では「表示中のMailに未読はありません（未読全体 10件）」と表示する。

Filter状態はDBへ保存せず、ページ再読込で「すべて」に戻る。

### 最終更新日時

取得成功後、Mail Widgetのツールバー右側へ `更新 HH:mm` を表示する。

失敗時は新しい更新時刻へ書き換えない。

## Read-only境界

V1.12-Gでも次を維持する。

- 一覧は `EXAMINE('INBOX')`
- `MessageQuery` は `leaveUnread()`
- 本文Previewは従来どおりPEEK
- `STORE` を追加しない
- 既読/未読変更を追加しない
- 削除を追加しない
- 移動/コピーを追加しない
- 送信を追加しない

未読件数取得に使うFolder statusも参照処理のみである。
