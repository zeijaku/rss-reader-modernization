# V1.12-H Mail 検索 / 送信者Filter

## 目的

V1.12-Gのread-only Mail Widgetを維持したまま、Mailを探しやすくする。

1. 件名検索
2. From検索
3. 表示結果の送信者Filter

Checkpoint version: `1.12.0-dev.8`
Baseline: `rss-reader-modernization-1.12-G-mail-unread-ux.zip`

## 検索仕様

Mail Widgetに検索欄を追加する。

- 検索対象: `件名` / `From`
- 検索語: 最大128文字
- 空欄で検索した場合は通常の最新Mail取得
- 検索解除ボタンで通常表示へ戻る
- 検索条件はDBへ保存しない
- Widget更新時は現在入力されている検索条件を再利用する

検索はブラウザで取得済み5/10件だけを対象にせず、IMAPの検索条件としてINBOXへ渡す。
ImapEngineのMessageQueryに対して `subject()` または `from()` を使用し、一致したMailから新しい順にWidgetの表示上限5/10件を取得する。

検索では本文を対象にしない。V1.12-Hは件名とFromのみに限定する。

## 送信者Filter

検索とは別に、現在取得済みのMailから送信者候補を作り、プルダウンで表示を絞り込めるようにする。

- `from_email` があればメールアドレスを内部Filter keyに使用
- なければ表示用From文字列を使用
- Filter操作だけではIMAPへ再接続しない
- 未読Filterと併用可能
- 検索を新しく実行した場合は送信者Filterを解除する
- Filter状態はDBへ保存しない

送信者Filterは「現在取得した検索結果または最新5/10件」の範囲だけを対象とする。
INBOX全体を送信者で検索したい場合は、検索対象を `From` にして検索する。

## 未読件数

`未読 N` はV1.12-Gと同じくINBOX全体のUNSEEN件数を表示する。
検索結果件数や送信者Filter後の件数には変更しない。

## Read-only境界

V1.12-Hでも次を維持する。

- `EXAMINE('INBOX')`
- `MessageQuery::leaveUnread()`
- 本文PreviewはPEEK
- 検索はMessageQueryのread-only criteriaのみ
- `STORE` を追加しない
- 既読/未読変更を追加しない
- 削除を追加しない
- 移動/コピーを追加しない
- 送信を追加しない

## 安全性

- Search typeは `subject` / `from` のallow-list
- Search queryは最大128文字で既存text validationを通す
- ブラウザへ返す件名/Fromは従来どおり安全化済み文字列
- 送信者候補はjQuery `.text()` で生成しHTMLとして解釈しない
- Search queryの復元はinput `.val()` を使用
