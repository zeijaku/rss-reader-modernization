# V1.43.0-dev.1: Cursor Field free-body physics

Application / Asset Revision: `1.43.0-dev.1`。

Base: V1.42.0正式版。今回のRuntime変更対象はCursor Fieldだけで、他Game / Calendar / DB / API / Auth / Saveには触れない。

## Behavior

- 初期状態は○/□を合計3個配置する。
- 初期物体はWidget内を低速で自由移動し、内壁で反射する。
- ○/□同士は衝突時に速度を交換/反射する。□の回転は導入せず、向きは固定する。
- Mouse / Pen pointerを小さな円形Colliderとして扱う。静止Cursorへ当たっても反射し、速く動かしたCursorは速度の一部を物体へ渡す。
- 空いている場所をClickすると、その位置へ○/□を交互に1個追加する。追加物体は速度0で開始し、既存物体またはCursorとの衝突で動き始める。
- 物体上Clickでは追加しない。最大24個。
- Resizeでは物体を再生成せず、既存位置/速度を新しいCanvas寸法へ比例変換する。
- Score / Clear / Game Over / browser save / network通信は追加しない。Reloadで初期状態へ戻る。

## Lifecycle / accessibility

- requestAnimationFrameを使用し、Widgetがviewport外またはPage hidden時は停止する。
- `prefers-reduced-motion: reduce` では初期の自律速度を0にし、静的なFieldからUser操作でのみ動かせる。
- Canvasは従来どおりKeyboard focus可能で、説明文とaria-labelを更新する。

1. 何もしない状態で○/□が自然な速度で漂い、壁や互いに当たって方向が変わる。

3. 空白Clickで静止物体が増え、Click直後に勝手に飛ばない。
4. 物体上Clickでは増えない。
5. Widget幅変更後も数とおおよその配置が維持される。
